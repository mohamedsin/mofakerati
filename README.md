# مفكرتي - تطبيق ملاحظات (PWA)

تطبيق خفيف شبه Google Keep، يشتغل أوفلاين 100%.

## المميزات
- ملاحظات نصية
- قوائم مهام
- ألوان
- تثبيت
- بحث
- نسخ احتياطي واسترجاع
- يشتغل بدون إنترنت بعد أول فتح
- واجهة عربية

## طريقة الاستخدام

### 1. ارفع الملفات على استضافة مجانية (HTTPS مطلوب)

أسهل طريقة:

**GitHub Pages (مجاني):**
1. اعمل حساب على github.com
2. اعمل Repository جديد
3. ارفع كل ملفات المجلد ده
4. من Settings → Pages → فعّل GitHub Pages
5. هياخد لينك زي: `https://yourname.github.io/repo-name/`

أو استخدم:
- Netlify Drop (netlify.com/drop) → اسحب المجلد
- Cloudflare Pages
- Vercel

### 2. افتح الرابط على كروم في الموبايل
### 3. اضغط القائمة ⋮ → "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق"
### 4. خلاص بقى عندك تطبيق
